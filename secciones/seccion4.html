1. La Shell de Linux

La shell (o interfaz de línea de comandos) es un programa que permite al usuario interactuar con el sistema operativo mediante comandos de texto. Es el intermediario entre el usuario y el kernel de Linux.

Tipos de shell más comunes:

  • bash (Bourne Again SHell): La más utilizada por defecto en la mayoría de distribuciones Linux.
  • zsh (Z Shell): Muy popular en Arch Linux y usada por defecto en macOS desde Catalina.
  • sh (Bourne Shell): La shell original de Unix.
  • fish: Shell moderna con autocompletado avanzado.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ echo $SHELL
# Generalmente bash
# /bin/bash
bash es la shell por defecto. 		$SHELL
# bash o zsh según config
# /bin/bash o /bin/zsh
Arch usa bash; zsh es muy popular aquí. 		$ echo $SHELL

bash es la shell por defecto.

SHELL

history

Muestra el historial de comandos ejecutados en la shell. Cada línea tiene un número de identificación.

Uso:
 history [opciones]

Para qué sirve:
 Permite ver, buscar y reutilizar comandos que ya ejecutaste anteriormente. Muy útil para no tener que escribir comandos largos de nuevo.

Ejemplos por distribución

$ !23
Igual en Arch. El historial se guarda en ~/.bash_history o ~/.zsh_history según la shell. 		$ history
$ history 5
$ !10
Igual en Fedora. El historial se guarda en ~/.bash_history.

SHELL

type

Indica de qué tipo es un comando: si es un builtin de la shell, un alias, una función, o un programa externo con su ruta.

Uso:
 type [comando]

Para qué sirve:
 Saber si un comando es interno de la shell (builtin), un alias creado por ti, o un ejecutable externo ubicado en el sistema de archivos.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ type cd
$ type ls
$ type which
$ type cp
cd: builtin | ls: alias (generalmente) | which: hashed | cp: /usr/bin/cp 		$ type cd
$ type ls
$ type which
Mismo funcionamiento. En zsh puede dar resultados ligeramente distintos. 		$ type cd
$ type ls
$ type cp
Mismo funcionamiento que en Debian.
Resultados posibles del comando type:
  • is a shell builtin: El comando es interno de la shell (ej: cd, help)
  • is aliased to: El comando es un alias (ej: ls → ls --color=auto)
  • is hashed: La ruta ya fue resuelta y guardada en la hash table para mayor velocidad
  • is /ruta/al/ejecutable: Programa externo con su ubicacion en el sistema
Curiosidad: ¿Qué significa 'is hashed'?

Cuando la shell dice que un comando 'is hashed', significa que ya resolvio su ruta y la guardo en una hash table para acceder a ella mas rapido en el futuro. Esto evita buscar el archivo en el sistema cada vez que se ejecuta.

$ hash # Ver todos los comandos hasheados
$ hash -r # Limpiar la hash table

SHELL

ls

Lista el contenido de un directorio. Es uno de los comandos más utilizados en Linux.

Uso:
 ls [opciones] [directorio]

Para qué sirve:
 Ver los archivos y carpetas de un directorio. Con distintas opciones se puede ver información detallada como permisos, propietario, tamaño y fecha de modificación.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ ls
$ ls -l
$ ls -la
$ ls -lah
$ ls -lah Escritorio/
En Debian/Ubuntu la carpeta es 'Escritorio' en español. 		$ ls
$ ls -l
$ ls -la
$ ls -lah
$ ls -lah Desktop/
En Arch el directorio por defecto suele ser 'Desktop' en inglés. 		$ ls
$ ls -l
$ ls -la
$ ls -lah
$ ls -lah Escritorio/
En Fedora suele ser 'Escritorio' en español como en Debian.
Opciones más importantes de ls:
  • -l → Muestra listado largo con permisos, propietario, tamaño y fecha.
  • -a → Muestra archivos ocultos (los que empiezan con punto).
  • -h → Muestra el tamaño en formato legible (KB, MB, GB).
  • -lah → Combinación de los tres anteriores. La más completa y usada.

4. Manejo de Comandos y Expresiones Lógicas

La shell permite combinar varios comandos en una sola línea usando operadores. Esto hace posible crear flujos de ejecución condicionales o secuenciales.

Operador Comportamiento Ejemplo
&& AND: el segundo comando solo se ejecuta si el primero tuvo exito (exit code 0). clear && ls -lah
|| OR: el segundo comando se ejecuta solo si el primero FALLO (exit code distinto de 0). comando_invalido || ls
; Secuencial: ejecuta los comandos uno tras otro independientemente del resultado de cada uno. clear ; ls

Operador && (AND lógico)

Ejecuta el segundo comando SOLO si el primero fue exitoso. Si el primer comando falla, el segundo no se ejecuta.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ clear && ls
$ clear && ls -lah
$ mkdir test && cd test
Si 'clear' falla, 'ls' no se ejecuta. Util para encadenar operaciones que dependen entre si. 		$ clear && ls
$ pacman -Sy && pacman -Su
$ mkdir test && cd test
Usado mucho en Arch para actualizar: primero sincroniza, luego actualiza solo si tuvo exito 		$ clear && ls
$ dnf check-update && dnf upgrade
$ mkdir test && cd test
Mismo uso en Fedora con el gestor de paquetes dnf.

Operador || (OR lógico)

Ejecuta el segundo comando SOLO si el primero FALLO. Es el comportamiento opuesto al &&.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ cleasadasd || ls
$ ls /no_existe || echo 'Error'
$ ls || ls -lah
Como 'cleasadasd' no existe y falla, 'ls' SI se ejecuta. 'ls || ls -lah' → solo ejecuta 'ls', el segundo se omite porque el primero tuvo exito. 		$ comando_invalido || ls
$ ls /no_existe || echo 'Error'
Mismo comportamiento. El segundo comando actua como 'plan B'. 		$ comando_invalido || ls
$ ls /no_existe || echo 'Error'
Mismo comportamiento en Fedora.

Operador ; (Secuencial)

Ejecuta todos los comandos en orden, independientemente de si alguno falla o no. No hay condicion, simplemente se ejecutan uno tras otro.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ clear ; ls
$ date ; whoami ; ls
$ echo 'Hola' ; ls
Equivalente a escribir los comandos en lineas separadas. Se ejecutan todos aunque alguno falle. 		$ clear ; ls
$ date ; whoami ; ls
Mismo comportamiento en Arch. 		$ clear ; ls
$ date ; whoami ; ls
Mismo comportamiento en Fedora.

5. Creando Comandos Propios con alias

Un alias es un nombre personalizado que le asignas a un comando o a una combinación de comandos. Son atajos que puedes definir tu mismo para no tener que escribir comandos largos repetidamente.

SHELL

alias

Permite crear un nombre personalizado (alias) para un comando o serie de comandos. Ejecutado sin argumentos, lista todos los alias activos.

Uso:
 alias [nombre]='comando'

Para que sirve:
Crear atajos personalizados para comandos que usas frecuentemente. Por ejemplo, en lugar de escribir 'clear ; ls' cada vez, puedes crear el alias 'clist'.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ alias
$ alias clist='clear ; ls'
$ clist
$ alias ll='ls -lah'
Los alias creados solo duran mientras la sesion esta activa. Para hacerlos permanentes, agrega la linea al archivo ~/.bashrc 		$ alias
$ alias clist='clear ; ls'
$ clist
$ alias ll='ls -lah'
En Arch con zsh, agrega los alias en ~/.zshrc para que sean permanentes. 		$ alias
$ alias clist='clear ; ls'
$ clist
$ alias ll='ls -lah'
Igual en Fedora. Agrega en ~/.bashrc para persistencia
tty_register // simulate --alias-creation
user@machine:~#

Hacer un alias permanente:

Los alias definidos en la terminal se pierden al cerrar la sesión. Para hacerlos permanentes debes agregarlos a tu archivo de configuración de la shell:

$ nano ~/.bashrc → Abrir el archivo de configuracion
alias clist='clear ; ls' → Agregar esta linea al final del archivo
$ source ~/.bashrc → Recargar la configuracion sin reiniciar
Nota:

apropos es equivalente a man -k. Ambos buscan en las descripciones de las páginas del manual.

SHELL

unalias

Elimina un alias creado previamente. El alias deja de existir inmediatamente.

Uso:
 unalias [nombre_del_alias]

Opciones útiles:
Borrar un alias que ya no necesitas o que quieres redefinir. Si intentas usar el alias despues de borrarlo, la shell dira que el comando no existe.

Ejemplos por distribución

Debian / Ubuntu Arch Linux Fedora
$ unalias clist
$ type clist # Error: no existe
$ unalias -a # Borra todos los alias
Tras ejecutar 'unalias clist', si escribes 'clist' obtendras: bash: clist: command not found 		$ unalias clist
$ type clist # Error: no existe
$ unalias -a
Mismo comportamiento en Arch. 		$ unalias clist
$ type clist # Error: no existe
$ unalias -a
Mismo comportamiento en Fedora.

6. Atajos útiles para la Shell de Linux

Estos atajos de teclado funcionan en la shell bash (y en la mayoría de shells de Linux). Dominarlos aumenta significativamente la velocidad de trabajo en la terminal.

// Navegación en la línea de comandos:

Ctrl + A Mueve el cursor al PRINCIPIO de la línea actual.
Ctrl + E Mueve el cursor al FINAL de la línea actual.
Alt + F Avanza el cursor UNA PALABRA hacia adelante.
Alt + B Retrocede el cursor UNA PALABRA hacia atrás.
Tab AUTOCOMPLETA automáticamente nombres de archivos, carpetas y comandos.

// Edición y borrado:

Ctrl + U Borra todo el texto desde el cursor hacia la IZQUIERDA.
Ctrl + K Borra todo el texto desde el cursor hacia la DERECHA.
Ctrl + W Borra la PALABRA ANTERIOR completa antes del cursor.
Ctrl + H Borra el CARÁCTER ANTERIOR (equivalente a Backspace).
Ctrl + T INTERCAMBIA la posición del carácter actual con el anterior.
Esc + T INTERCAMBIA la posición de la palabra actual con la anterior.
Alt + l/u Convertir la palabra actual a MINUSCULAS (l) o MAYUSCULAS (u).

// Control del programa y pantalla:

Ctrl + L LIMPIAR la consola por completo (idéntico al comando clear).
Ctrl + C Envía SIGINT para INTERRUMPIR/CANCELAR la ejecucion del programa actual.
Ctrl + D CERRAR la shell actual (equivalente a escribir 'exit').
Ctrl + R BUSCAR en el historial de comandos. Escribe parte del comando y lo encuentra automaticamente
Alt + . o !$
Inserta el ULTIMO ARGUMENTO del comando anterior. Muy util para no repetir rutas largas.
Alt + . o !$

Ejemplo práctico: Insertar último argumento

Inserta de forma automatizada el último argumento del comando anterior. Ideal para optimizar flujos interactivos al manipular directorios y rutas anidadas complejas.

# Paso 1: Examinar una ruta extensa
$ ls -lah /home/usuario/Documentos/proyectos/
# Paso 2: Escribir comando y presionar el atajo
$ cd <Alt + .>
# La terminal expande la cadena automáticamente a:
$ cd /home/usuario/Documentos/proyectos/
