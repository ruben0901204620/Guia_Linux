1. Navegación: Rutas Absolutas y Relativas

En Linux todo el sistema de ficheros parte de un único directorio raíz llamado / (slash). Para moverte entre directorios debes entender la diferencia entre rutas absolutas y relativas.

// Ruta ABSOLUTA

Siempre empieza desde la raíz /.

Funciona sin importar donde estés actualmente.

$ cd /home/ruben/Escritorio/

// Ruta RELATIVA

Parte desde donde estás ahora mismo.

Depende del directorio actual de trabajo.

$ cd Escritorio/

Símbolos especiales de navegación

Opción Descripción
/ Directorio raíz del sistema. Punto de partida de todas las rutas absolutas.
~ Directorio home del usuario actual. Equivalente a /home/usuario.
. El directorio actual en el que te encuentras.
.. El directorio padre (un nivel arriba) del directorio actual.
- El directorio anterior (vuelve al último directorio visitado).
SHELL

pwd — Print Working Directory

Muestra la ruta absoluta de la ubicación de trabajo actual.

tty // pwd-check
user@machine:~#
SHELL

cd / — Ir a la Raíz

tty // cd-root
user@machine:~#
SHELL

cd Escritorio/ — Navegación Relativa

tty // cd-relative
user@machine:~#
SHELL

cd .. — Directorio Padre

tty // cd-father
user@machine:~#
SHELL

cd ~ — Regresar al Home

tty // cd-home
user@machine:~#
SHELL

cd - — Directorio Anterior

tty // cd-previous
user@machine:~#
Diferencia entre cd . y cd ..
  • cd . → Se mantiene en la misma posición (no genera cambios prácticos).
  • cd .. → Retorna un nivel hacia la estructura contenedora padre.

2. Ficheros en Linux

En Linux "todo es un fichero": los directorios, dispositivos, procesos, conexiones de red... todo se representa y gestiona de manera unificada bajo la misma abstracción dentro del sistema[cite: 40].

Tipos de Ficheros en el Sistema [cite: 42]

Tipo / Opción [cite: 43] Descripción [cite: 43]
Fichero regular [cite: 43] El tipo más común: texto, binarios, scripts, imágenes, etc. [cite: 43]
Directorio [cite: 43] Un fichero especial que contiene referencias a otros ficheros[cite: 43].
Enlace simbólico [cite: 43] Un puntero (acceso directo) que apunta a otro fichero o directorio[cite: 43].
Fichero de bloque [cite: 43] Representa dispositivos de almacenamiento físico como discos duros (/dev/sda)[cite: 43].
Fichero de carácter [cite: 43] Representa dispositivos de flujo secuencial como terminales o puertos serie[cite: 43].
Socket [cite: 43] Canal de red o socket local usado para comunicación interna entre procesos[cite: 43].
Named pipe (FIFO) [cite: 43] Canal de comunicación unidireccional entre procesos en estricto orden FIFO[cite: 43].

ls — Listar Contenido Básico

Descripción: Permite visualizar los archivos presentes en el directorio actual. Dependiendo de la distribución, el nombre de los directorios predeterminados del Home del usuario puede variar.

tty // ls-check
user@machine:~#
Debian / Ubuntu

El Home mapea carpetas traducidas en español de manera predeterminada como Escritorio/.

Arch Linux

Por defecto las rutas de entorno e inicialización se configuran estrictamente en inglés como Desktop/.

Fedora

Suele heredar los localismos completos del instalador de sistema, asignando Escritorio/.

ls -la — Listar Todo Detalladamente [cite: 105, 106]

Descripción: Despliega una vista extendida incluyendo permisos, tamaños legibles y ficheros ocultos (aquellos cuyo nombre arranca por un punto (.))[cite: 105, 106].

tty // ls-la
user@machine:~#

tree — Árbol de Directorios [cite: 19]

Descripción: Muestra de forma jerárquica y visual la arquitectura interna de un directorio sin tener que navegar iterativamente con comandos secuenciales[cite: 22, 24]. Nota de Dependencia: No suele venir preinstalado nativamente en los entornos mínimos[cite: 26].

Opción [cite: 28]Efecto Operativo [cite: 28]
-L [n] [cite: 28]Limita el árbol a n niveles de profundidad de escaneo (Ej: tree -L 2 /)[cite: 28].
-d [cite: 28]Omite el listado de archivos individuales; despliega únicamente los directorios[cite: 28].
-a [cite: 28]Fuerza la inclusión de ramas que contengan ficheros ocultos dentro de la estructura[cite: 28].
-h [cite: 28]Acompaña las etiquetas de tamaño con formato legible para humanos (KB, MB, GB)[cite: 28].
tty // tree-check
user@machine:~#
📦 APT (Debian/Ubuntu) [cite: 26] $ sudo apt install tree [cite: 21]
📦 PACMAN (Arch Linux) [cite: 26] $ sudo pacman -S tree [cite: 26]
📦 DNF (Fedora) [cite: 26] $ sudo dnf install tree [cite: 26]

file — Firma E Identidad de Ficheros [cite: 44]

Descripción: Determina de forma precisa la naturaleza de un elemento analizando su cabecera y búfer de metadatos internos[cite: 46]. Recuerda: Linux es agnóstico a las extensiones; un archivo .jpeg renombrado a .txt seguirá siendo detectado por su tipo real[cite: 47, 49].

tty // file-check
user@machine:~#

3. Creación de Ficheros y Editores de Texto

Asignación de espacio lógico, inicialización de estructuras de directorios y manipulación de buffers de texto plano directamente en el sistema de archivos. Linux ofrece múltiples editores internos con características y curvas de aprendizaje adaptadas a cada necesidad[cite: 64, 65].

Sensibilidad a Mayúsculas (Case Sensitive)

El sistema de archivos de Linux distingue estrictamente entre mayúsculas y minúsculas. Por ejemplo, las carpetas test y Test son tratadas como directorios totalmente distintos e independientes.

mkdir — Make Directory

Descripción: Crea uno o varios directorios dentro del árbol jerárquico del sistema[cite: 56, 59].

OpciónEfecto Operativo
-p Crea directorios padres intermedios de forma automática si no existen, evitando errores si la ruta ya está creada.
-v Modo informativo (Verbose): Imprime un mensaje de confirmación por cada directorio creado.
tty // mkdir-simple
user@machine:~#
tty // mkdir-parents
user@machine:~#

Ecosistema de Editores de Texto en Linux

Diferentes entornos de software disponibles para administrar archivos sin salir de la shell[cite: 63, 64]:

Editor Dificultad Descripción y Uso Básico
nano Fácil El más intuitivo para principiantes. Expone su barra de atajos visibles en la parte inferior de la pantalla[cite: 66, 70]. Salida rápida con Ctrl+X.
pico Fácil Antecesor histórico de nano. En entornos actuales suele estar enlazado o redirigido directamente a nano debido a su uso equivalente.
vi / vim Avanzado Herramienta de edición por modos (*Normal, Inserción, Visual*). Requiere pulsar i para insertar datos , :q! para salir sin salvar y :wq para guardar.
emacs Avanzado Extensible y complejo. Se puede invocar en interfaz gráfica o en consola con la bandera -nw. Finaliza ejecución mediante Ctrl+X Ctrl+C.

nano — Editor Recomendado para Principiantes

Descripción: Permite inicializar o modificar documentos de texto plano[cite: 72]. Si el archivo especificado no existe en la ruta de trabajo, nano lo creará automáticamente al confirmar el guardado de los búfers[cite: 73].

tty // nano-edit
user@machine:~#
Atajos Operativos Esenciales (Combinaciones Clave)
Ctrl + O Guardar archivo
Ctrl + X Salir del editor
Ctrl + K Cortar línea
Ctrl + W Buscar palabra
Debian / Ubuntu

Viene incorporado de forma nativa e integrada por defecto en el sistema operativo.

Arch Linux

Puede no venir preinstalado en despliegues mínimos. Requiere instalación manual:

$ sudo pacman -S nano
Fedora

No se incluye en ciertas imágenes Core. Requiere aprovisionamiento explícito:

$ sudo dnf install nano

4. Visualización de Contenido

Inspección del contenido interno de los ficheros de datos directamente en la consola sin necesidad de editores de texto[cite: 77]. Linux implementa comandos diferenciados según el volumen de datos y la libertad de navegación requerida en el búfer[cite: 78].

Matriz Operativa: Diferencias entre cat, more y less
Comando Comportamiento Operativo Caso de Uso Recomendado
cat Vuelca la totalidad del contenido del archivo en la terminal de una sola vez[cite: 81]. Lectura rápida de ficheros de texto pequeños[cite: 84].
more Paginación secuencial básica. Solo permite avanzar hacia adelante[cite: 91]. Alternativa básica integrada para archivos medianos[cite: 91, 93].
less Paginación avanzada con navegación bidireccional libre y búsquedas[cite: 99]. Recomendado para ficheros grandes, documentación larga y logs del sistema[cite: 103, 106].

cat — Concatenate

Uso: cat [fichero] [cite: 83] | Su nombre deriva de "concatenate", debido a su capacidad intrínseca para unificar múltiples flujos de archivos[cite: 82].

⚠️ Advertencia de rendimiento: No es idóneo para archivos de gran escala (como logs masivos), ya que arroja todo el flujo sin pausas ni control visual en la pantalla.
tty // cat-check
user@machine:~#

more — Visualización Paginada Básica

Uso: more [fichero] [cite: 92] | Segmenta el contenido en bloques según el tamaño vertical de la terminal activa, deteniendo el flujo al final de cada página[cite: 90]. Su principal limitación es la imposibilidad de retroceder en el historial de lectura[cite: 91, 94].

Siguiente Página: Espacio [cite: 96]
Siguiente Línea: Enter [cite: 96]
Terminar/Salir: q [cite: 96]

less — Visualización Paginada Avanzada

Uso: less [fichero] [cite: 101] | Constituye un programa binario externo independiente (no builtin) que se erige como la evolución directa y optimizada de more[cite: 100]. Garantiza navegación libre interactiva en todas las direcciones dentro del búfer de datos[cite: 99].

Atajos Operativos de Interfaz (Navegación Interactiva)
Flechas / j / k [cite: 105] Desplazar línea a línea [cite: 105]
Espacio / b [cite: 105] Avanzar / Retroceder Página [cite: 105]

5. Manipulación, Borrado y Búsqueda

Operaciones transaccionales básicas sobre la estructura de inodos para mover, duplicar, purgar o localizar ficheros de datos dentro del árbol jerárquico del sistema[cite: 107].

Matriz de Comportamiento: cp vs mv
Comando Efecto en el Fichero Original Acción en Destino
cp Lo deja completamente intacto en su ruta raíz[cite: 128]. Duplica y genera un nuevo registro binario independiente[cite: 112].
mv Lo elimina de la ubicación de origen de forma inmediata[cite: 124, 128]. Lo coloca en la nueva ruta o cambia su nombre (renombrado)[cite: 121, 128].

cp — Copiar Fichero (Copy)

Uso: cp [opciones] origen destino | Duplica un archivo regular en otra ubicación[cite: 111, 112]. Por defecto, si el destino ya existe, lo sobrescribe sin emitir advertencias previas[cite: 115].

⚠️ Modo Seguro (-i): Añade confirmación interactiva antes de sobrescribir[cite: 113, 117].
📋 Atributos (-p): Conserva permisos estructurales, propietarios y marcas de tiempo originales[cite: 117].
tty // cp-file
user@machine:~#

cp -r — Copia Recursiva de Carpetas

El comando base cp no es capaz de procesar directorios de forma nativa e interrumpe el flujo emitiendo un error[cite: 110, 135]. Es imperativo inyectar el flag -r o --recursive para replicar jerárquicamente carpetas enteras y todo su contenido interno[cite: 110, 117].

tty // cp-dir
user@machine:~#

mv — Mover o Renombrar (Move / Rename)

Uso: mv [opciones] origen destino | Reubica archivos o directorios dentro del árbol de almacenamiento[cite: 120]. Si la operación se ejecuta dentro de la misma ruta de trabajo pero asignando un nombre diferente, actúa de forma nativa como una rutina de **renombrado**[cite: 121, 126].

⚙️ Flag estratégico (-u / Update): Mueve de manera selectiva únicamente si el archivo origen cuenta con una fecha de modificación más reciente que el fichero homónimo en el destino[cite: 127].
tty // mv-file
user@machine:~#

rm — Eliminar Archivo (Remove)

Uso: rm [opciones] fichero | Elimina registros de datos de forma directa y permanente[cite: 131].

🛑 Principio Crítico de la Consola: En la terminal de Linux no existe papelera de reciclaje[cite: 131, 137]. Cualquier borrado es irreversible y purga las referencias de almacenamiento del sistema para siempre[cite: 131, 137]. Para directorios completos, arrojará un error a menos que se use el flag de recursividad -r[cite: 135, 137].
tty // rm-file
user@machine:~#

rm -rf — Eliminación Forzada (Crítico)

Fusión destructiva de los modificadores -r (recursivo) y -f (fuerza)[cite: 136]. Ordena al sistema la purga total de estructuras de directorios completas, anulando de forma absoluta cualquier confirmación interactiva o alerta por archivos inexistentes[cite: 136].

🚨 Restricción Absoluta: Jamás ejecute un comando estructurado como rm -rf /, ya que iniciará la destrucción en cadena de la totalidad del sistema de ficheros desde el directorio raíz[cite: 137].
tty // rm-rf
user@machine:~#

find — Búsqueda Avanzada Multi-Criterio

Uso: find [directorio_inicio] [criterios] | Rastrea de forma exhaustiva el almacenamiento aplicando filtros dinámicos como patrones de nombres, tipo de objeto, propietarios o tamaños[cite: 141, 142].

Modificadores Avanzados de Rastreo
-name / -iname Filtra por nombre completo o patrón con comodines (*). -iname ignora mayúsculas[cite: 147].
-type f / -type d Segmenta la salida discriminando por tipo de inodo: f para ficheros regulares o d para directorios[cite: 147].
2> /dev/null Redirige los flujos de error (ej: 'Permission denied') hacia el dispositivo virtual nulo, limpiando el output[cite: 147].
tty // find-name
user@machine:~#

6. Métodos de Búsqueda Exhaustiva

Localización avanzada e indexación en tiempo real de recursos del sistema. Linux provee herramientas para auditar inodos basándose tanto en metadatos del archivo como en expresiones regulares aplicadas a su contenido interno.

Estrategias de Rastreo: Infraestructura vs Contenido
Herramienta Mecánica de Rastreo Criterios Clave de Filtrado
find Inspecciona el sistema de archivos buscando objetos que coincidan con metadatos específicos. Nombre, extensión, permisos, tamaño, inodos, fechas de modificación.
grep Escanea líneas de texto plano dentro de ficheros buscando patrones o expresiones regulares. Cadenas de caracteres, palabras exactas, exclusión de líneas, patrones Regex.
SHELL

find — Auditoría de Metadatos

Sintaxis: find [ruta_búsqueda] [criterios]
Escanea de manera recursiva e interactiva el árbol de directorios cruzando restricciones lógicas complejas en tiempo real.

Filtros por Atributo Físico
  • -size +50M: Archivos de tamaño mayor a 50 Megabytes.
  • -mtime -7: Modificados en los últimos 7 días.
  • -user root: Recursos que pertenezcan al usuario root.
Filtrado Seguro de Mensajes

Al buscar desde la raíz (/), agregar 2> /dev/null al final canaliza los errores de permisos denegados al dispositivo nulo del kernel, limpiando el output.

ruben@titan:~$

Sintaxis: grep [opciones] "patrón" [fichero]
Procesa ficheros de texto línea por línea en busca de coincidencias con un patrón específico, imprimiendo únicamente los registros válidos.

Modificadores de Filtrado de Cadenas
-i Ignora mayúsculas/minúsculas
-r Búsqueda recursiva en directorios
-v Invierte la selección (excluir)
-n Muestra el número de línea exacto

7. Estándar de Jerarquía del Sistema (FHS)

Las distribuciones corporativas de Linux implementan el estándar FHS (Filesystem Hierarchy Standard). Esta convención rígida organiza el propósito exacto de cada directorio para garantizar la portabilidad, interoperabilidad y predictibilidad de las aplicaciones y subsistemas.

// Estructura integral de la raíz (tree -L 1 /)
/ (Raíz absoluta del sistema de ficheros)
├── bin    → Binarios fundamentales de los comandos globales (ls, cp, cat)
├── sbin   → Binarios del sistema para tareas de administración (reboot, fdisk)
├── etc    → Ficheros de configuración estáticos de servicios y del sistema
├── home   → Carpetas personales aisladas para los usuarios estándar
├── root   → Directorio doméstico exclusivo y privado del superusuario root
├── usr    → Jerarquía secundaria de lectura para usuarios (programas, librerías)
├── var    → Datos variables dinámicos (ficheros de log, colas de impresión, bases de datos)
├── dev    → Nodos lógicos de dispositivos físicos e interfaces de hardware
├── proc   → Sistema de archivos virtual basado en memoria que expone el estado del Kernel
└── sys    → Subsistema virtual jerárquico para interactuar con los controladores del núcleo
Directorio Propósito Crítico en Arquitectura
/ Raíz absoluta (Root Partition): El punto de partida de todo el sistema jerárquico. Cualquier elemento físico, lógico o montado en red arranca desde este nodo principal.
/bin Binarios Esenciales de Usuario: Ejecutables fundamentales y globales utilizables por cualquier rol o cuenta del sistema (cat, ls, mkdir, cp).
/sbin Binarios del Sistema (System Binaries): Comandos de administración y mantenimiento esenciales reservados para el administrador (reboot, fdisk, ifconfig). Suelen requerir privilegios de superusuario.
/etc Configuración del Sistema (Etcétera): Ficheros de configuración planos y específicos del host para controlar servicios locales y subsistemas esenciales (/etc/hosts, /etc/fstab, /etc/passwd).
/home Directorios de Usuarios: Espacio de almacenamiento doméstico y persistente aislado jerárquicamente para que los usuarios estándar salven sus configuraciones personales y datos de trabajo.
/root Home del Superusuario: El directorio doméstico privado asignado en exclusividad al usuario administrativo root. Se sitúa fuera de /home para garantizar disponibilidad si la partición de usuarios no se puede montar.
/usr Utilidades de Usuario (User System Resources): Históricamente la jerarquía secundaria compartida. Almacena la gran mayoría de programas, librerías compartidas (/usr/lib) y documentación técnica no esencial para el arranque mínimo.
/var Datos Variables: Contenedor para archivos de crecimiento dinámico y transitorio en producción, tales como logs de auditoría (/var/log), bases de datos activas y colas de impresión o correo electrónico.
/tmp Archivos Temporales: Espacio reservado para que las aplicaciones almacenen datos volátiles de corta duración. En muchos sistemas modernos se monta directamente sobre memoria RAM (tmpfs) y se purga automáticamente en cada reinicio.
/opt Paquetes Opcionales (Optional): Ubicación estandarizada para instalar paquetes de software y aplicaciones de terceros monolíticas o comerciales que no siguen la estructura tradicional de distribución.
/dev Nodos de Dispositivos (Devices): Ficheros especiales que actúan como interfaces directas con el hardware conectado al sistema (ej: discos duros en /dev/sda, terminales virtuales en /dev/tty1). En Linux, todo hardware se gestiona como un archivo.
/proc Procesos del Sistema (Virtual FS): Sistema de ficheros pseudo-virtual generado dinámicamente en memoria RAM por el núcleo. Expone información detallada en tiempo real de los procesos activos e hilos de ejecución (/proc/$PID).
/sys Subsistema del Kernel (Virtual FS): Interfaz del kernel estructurada jerárquicamente en memoria que sirve para consultar y alterar dinámicamente los parámetros operativos de los controladores de dispositivos y funciones avanzadas del núcleo.
/mnt  /media Puntos de Montaje: /mnt está destinado al montaje manual y temporal de sistemas de archivos por el administrador. /media se utiliza para el automontaje dinámico de medios extraíbles como unidades USB o lectores de CD-ROM.
